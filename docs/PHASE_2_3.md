# Phase 2 + 3 (ระหว่างรอ Play review)

ทำในโค้ดแล้ว:

## เฟส 2
- **สลิป QR** — ลูกค้าอัปโหลดสลิป → สถานะ `awaiting_confirm` → แอดมินกดยืนยันรับเงิน
- **จำกัด OTP** — request สูงสุด 5 ครั้ง / 15 นาที, verify 20 ครั้ง
- **เพดาน COD** — ค่าเริ่มต้น ฿3,000 (แอดมินตั้งที่ การชำระเงิน; 0 = ไม่จำกัด)
- **KYC UI** — ร้านที่ยังไม่อนุมัติเห็นปุ่มส่งเอกสารแทนสินค้า
- **ช่องทางช่วยเหลือ** — ค่าเริ่มต้นปิดอยู่ ต้องตั้งในแอดมิน
- **SEED_DEMO=0** — ข้าม seed ร้าน/สินค้าเดโมบน DB ใหม่

## เฟส 3 (ที่ทำแล้ว / ข้าม)
- **ลิงก์ติดตามพัสดุ** ตามขนส่ง — ทำแล้วในหน้ารายละเอียดออเดอร์
- **PWA manifest** — ทำแล้ว (ยังไม่มี service worker offline)
- **SMS OTP / บัตรเครดิต** — ข้ามตามนโยบายต้นทุน
- **คืนเงินเข้าบัญชีธนาคารจริง / FCM** — ยังไม่ทำ (ใช้กระเป๋าในแอป + แจ้งเตือนในแอป)

## Env แนะนำบน Render
```
AUTH_DEMO_OTP=0
AUTH_DEMO_SOCIAL=0
SEED_DEMO=0
JWT_SECRET=<สุ่มยาว>
```
