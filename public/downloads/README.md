# ดาวน์โหลด DeeJa APK (ทดสอบ)

เปิดลิงก์นี้บนมือถือ Android แล้วกดดาวน์โหลด:

**https://nappol-project.onrender.com/downloads/DeeJa.apk**

## ติดตั้ง
1. เปิดไฟล์ที่ดาวน์โหลด
2. ถ้าขึ้นเตือน — อนุญาต “ติดตั้งจากแหล่งนี้” (Chrome / Files)
3. กดติดตั้ง

หมายเหตุ: เป็น APK ทดสอบเอง ยังไม่ใช่จาก Play Store · ต้องมีเน็ตเพราะแอปโหลดเว็บจาก Render
